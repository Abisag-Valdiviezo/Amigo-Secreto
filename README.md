## Descripción del proyecto
**Amigo Secreto** es un juego donde los participantes ingresan sus nombres, y el sistema realiza un sorteo para asignar de forma aleatoria a cada persona un "amigo secreto". Este proyecto tiene como objetivo automatizar el proceso de asignación de manera justa y divertida, sin necesidad de hacerlo manualmente.

## Instalación
1. Clona el repositorio:

    ```bash
    git clone https://github.com/Abisag-valdiviezo/amigo-secreto.git
    ```

2. Navega a la carpeta del proyecto:

    ```bash
    cd amigo-secreto
    ```

3. Si deseas ejecutar el proyecto en un servidor local, puedes abrir el archivo `index.html` en un navegador o usar un servidor de desarrollo como [http-server](https://www.npmjs.com/package/http-server).

    Para instalar `http-server`:

    ```bash
    npm install -g http-server
    ```

    Luego, inicia el servidor con:

    ```bash
    http-server
    ```

4. Si deseas ejecutar el proyecto desde la consola con Node.js, puedes utilizar el script en `app.js`.

## Cómo jugar

1. Abre el archivo `index.html` en tu navegador (si usas la interfaz web) o ejecuta `node app.js` desde la consola (si prefieres la versión en consola).
2. Los jugadores ingresan sus nombres a través de la interfaz proporcionada.
3. El sistema realiza el sorteo y asigna a cada jugador un amigo secreto de manera aleatoria.
4. Los participantes reciben el nombre de su amigo secreto de manera confidencial.
5. ¡Disfruta del juego!

## Ejemplo de uso

### Versión Web:
- Abre el archivo `index.html` en tu navegador.
- Ingresa los nombres de los jugadores.
- Haz clic en "Realizar sorteo" y obtén la asignación de amigos secretos.

### Versión Consola:
1. Ejecuta `node app.js` desde la terminal.
2. Ingresa los nombres de los participantes cuando se te solicite.
3. El programa realizará el sorteo y te mostrará los resultados en la consola.
